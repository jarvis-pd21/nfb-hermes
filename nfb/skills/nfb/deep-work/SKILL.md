# Deep work (NFB)

Use this when a task needs many steps on this computer: writing or fixing code, building a small site or script,
editing many files, data cleanup, or a long research write-up saved to a file.

1. Write a clear task: the goal, the files or folder, what "done" looks like, and where to save the result.
2. Run it in the terminal: `deep-work "<task>" ~/work/<short-name>` (it can take minutes; it runs on my own prepaid brain).
3. Read the output and the files it made. Check the result yourself (run the code or open the file).
4. Tell the person what was done in plain words, with the file path or link.

Quick questions, chat, and one or two commands: do them yourself, don't delegate.
If it says "brain off (not prepaid)", say my balance needs a top-up first.
